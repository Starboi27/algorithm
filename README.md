# 알고리즘 풀이 기록

알고리즘 문제를 꾸준히 풀고, 풀이 과정을 기록하는 저장소입니다.

## 목표

- 매주 문제 10개 이상 풀이
- 한 문제를 풀고 나면 풀이 코드와 사용한 알고리즘을 정리
- 틀렸거나 오래 걸린 문제는 다시 풀어 보기

## 폴더 구조

```text
.
├── D1/            # Day 1 풀이
├── D2/            # Day 2 풀이
└── README.md
```

각 파일은 문제 번호를 이름으로 사용합니다.

```text
D1/6204.py  → 6204번 문제 풀이
```

## 주간 학습 체크

| 항목 | 목표 |
| --- | --- |
| 문제 풀이 수 | 10문제 이상 |
| 복습 | 어려웠던 문제 다시 풀기 |
| 기록 | 풀이 방법과 실수한 부분 정리 |

## 요일별 학습 계획

평일에 하루 2문제씩 풀면 주간 목표 10문제를 달성할 수 있습니다.

| 요일 | 목표 | 누적 |
| --- | --- | ---: |
| 월요일 | 2문제 | 2문제 |
| 화요일 | 2문제 | 4문제 |
| 수요일 | 2문제 | 6문제 |
| 목요일 | 2문제 | 8문제 |
| 금요일 | 2문제 | 10문제 |
| 토요일 | 못 푼 문제 보충 또는 복습 | - |
| 일요일 | 휴식 또는 다음 주 계획 세우기 | - |

## 풀이할 때 확인할 것

1. 입력과 출력 조건을 정확히 읽기
2. 시간 복잡도를 먼저 생각하기
3. 예제와 직접 만든 반례로 테스트하기
4. 풀이 후 다른 방법도 찾아보고 복습하기

꾸준히 한 문제씩 풀면서 문제 해결 능력을 쌓아가자.
