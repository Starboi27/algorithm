# 알고리즘 풀이 기록

알고리즘 문제를 꾸준히 풀고, 풀이 과정을 기록하는 저장소입니다.

## 목표

- 매주 문제 10개 이상 풀이
- 한 문제를 풀고 나면 풀이 코드와 사용한 알고리즘을 정리
- 틀렸거나 오래 걸린 문제는 다시 풀어 보기

## 폴더 구조

```text
.
├── Programmers/                # 프로그래머스 풀이
├── SWEA/
│   ├── D1/                     # SWEA D1 난이도
│   │   ├── 9_week_3/
│   │   ├── 9_week_4/
│   │   ├── 9_week_5/
│   │   ├── 10_week_2/
│   │   └── 10_week_3/
│   └── D2/                     # SWEA D2 난이도
│       ├── 9_week_3/
│       ├── 10_week_2/
│       └── 10_week_3/
├── 정처기 알고리즘/
│   ├── 9_week_4/
│   ├── 9_week_5/
│   ├── 10_week_2/
│   └── 10_week_3/
└── README.md
```

주간 폴더는 `월_week_주차` 형식을 사용합니다. 예를 들어 `10_week_3`는 10월 3주차입니다.

주차는 월요일 시작 달력 기준이며, 그달 1일이 포함된 주를 1주차로 셉니다.
2026년 9월 3주차는 9월 14~20일, 9월 5주차는 9월 28일~10월 4일,
10월 2주차는 10월 5~11일, 10월 3주차는 10월 12~18일입니다.

기존 `week_*` 폴더는 Git 최초 추가 기록을 기준으로 정리했습니다.
직접 모아 둔 10월 3주차 풀이·복습 자료는 해당 묶음을 유지합니다.
복습할 때는 각 사이트나 학습 분류 아래에서 같은 주차 폴더를 확인하면 됩니다.

문제 풀이 파일은 문제 번호를, 개념 연습 파일은 주제나 예제 번호를 이름으로 사용합니다.

```text
SWEA/D1/9_week_3/6204.py  → 9월 3주차의 SWEA D1 6204번 문제 풀이
정처기 알고리즘/10_week_3/BFS.py  → 10월 3주차의 BFS 학습
```

## 주간 학습 체크

| 항목 | 목표 |
| --- | --- |
| 문제 풀이 수 | 10문제 이상 |
| 복습 | 어려웠던 문제 다시 풀기 |
| 기록 | 풀이 방법과 실수한 부분 정리 |

## 요일별 학습 계획

평일에 하루 2문제씩 풀면 주간 목표 10문제를 달성할 수 있습니다.

| 요일 | 목표 | 누적 |
| --- | --- | ---: |
| 월요일 | 2문제 | 2문제 |
| 화요일 | 2문제 | 4문제 |
| 수요일 | 2문제 | 6문제 |
| 목요일 | 2문제 | 8문제 |
| 금요일 | 2문제 | 10문제 |
| 토요일 | 못 푼 문제 보충 또는 복습 | - |
| 일요일 | 휴식 또는 다음 주 계획 세우기 | - |

## 풀이할 때 확인할 것

1. 입력과 출력 조건을 정확히 읽기
2. 시간 복잡도를 먼저 생각하기
3. 예제와 직접 만든 반례로 테스트하기
4. 풀이 후 다른 방법도 찾아보고 복습하기

꾸준히 한 문제씩 풀면서 문제 해결 능력을 쌓아가자.
